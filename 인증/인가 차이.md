# 인증(Authentication)/인가(Authorization) 차이

## 1. 정의

- **인증 (Authentication)**  
  → 사용자의 신원을 확인하는 과정

- **인가 (Authorization)**  
  → 사용자의 권한을 확인하는 과정

---

## 2. 관계

- 인증 → 인가 (가능)
- 인가 → 인증 (불가능)

즉,  
**신원 확인이 먼저, 권한 확인은 그 다음 단계**

---

## 3. 인증 (Authentication)

### 개념
사용자가 누구인지 증명하는 과정

### 인증 요소 (3가지)

1. **아는 것 (Knowledge)**
    - 아이디, 비밀번호

2. **가지고 있는 것 (Possession)**
    - 휴대폰, OTP, 이메일 인증

3. **자신 자체 (Inherence)**
    - 지문, 얼굴, 홍채

### 핵심
- 시스템과 공유된 정보를 통해 신원 증명

---

## 4. 인가 (Authorization)

### 개념
인증된 사용자가 어떤 자원에 접근할 수 있는지 결정하는 과정

### 예시
- 일반 사용자 → 조회만 가능
- 관리자 → 수정, 삭제 가능

### 핵심
- 권한(Role, Permission)에 기반한 접근 제어

---

## 5. 예시로 이해하기

### 네이버 메일

1. 로그인 (아이디/비밀번호 입력)  
   → 인증

2. 메일 조회/삭제/설정  
   → 인가

---

### 카드키 시스템

- 카드키로 신원 확인  
  → 인증

- 특정 방 출입 가능 여부  
  → 인가

---

## 6. JWT에서의 역할

### 인증
- 로그인 성공 시 JWT 발급

### 인가
- JWT에 포함된 권한 정보로 접근 여부 판단

---

## 7. 인가 방식

### RBAC (Role-Based Access Control)
- 역할 기반 권한 관리
- 예: USER, ADMIN

### ABAC (Attribute-Based Access Control)
- 사용자 속성 기반 권한 관리
- 예: 나이, 위치, 시간

---

## 8. 핵심 정리

- 인증 = 신원 확인
- 인가 = 권한 확인
- 인증이 먼저 수행됨
- JWT는 인증 결과를 저장하고 인가에 활용됨

---

## 정리

인증은 "누구인지 확인", 인가는 "무엇을 할 수 있는지 확인"
